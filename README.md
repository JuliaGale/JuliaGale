# Julia Gale

Product designer specialising in design systems. Vancouver, Canada.

I turn vague asks into systems teams can build on: audit first, then architecture, tokens, components, and the documentation that keeps them in use.

### Recent work
- **Roblox:** 14 months embedded in the core design systems team, via Forge Studio. Built the input component family from zero on a three-layer nested architecture, cutting 627 variants to 140.
- **EarnIn:** audited the product before a system existed; my look-and-feel explorations set the semantic colour values behind light and dark mode.
- **Baseline:** a real-estate repair negotiation platform, designed with another designer and built mostly by Claude Code inside our shared system. I made its colour ramps: 13 ramps of 11 steps.
- **Building with AI:** I set the system and the rules; Claude Code writes the code, and a hook makes it run my checks after every edit. See [designing-with-agents](https://github.com/JuliaGale/designing-with-agents).
